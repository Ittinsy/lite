# lite
A lite fingerprint browser

Kernel: [fingerprint-chromium](https://github.com/adryfish/fingerprint-chromium) version 142.

Framework: Electron.

# How to use
Download the fingerprint-chromium release version 142 for your platform and extract it.

Rename the extracted folder to 'kernel' and place it next to the program (lite.exe on Windows and lite on Linux).

# How to build
For Windows:
```
npm install
```
```bash
npm run dist:win:dir
```

For Linux:
Use GitHub Actions workflow.
